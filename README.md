Website Institucional - ONG Mãos que Ajudam
1. Visão Geral do Projeto
Este projeto consiste num website institucional completo e moderno para a "ONG Mãos que Ajudam", uma organização fictícia focada em transformação social. O site foi desenvolvido utilizando as melhores práticas de HTML5 e CSS3, com uma estrutura semântica, design responsivo e recursos interativos avançados para proporcionar uma experiência de utilizador rica e acessível.

O principal objetivo foi criar uma plataforma web robusta que não só apresenta a organização e os seus projetos, mas também incentiva o envolvimento da comunidade através de voluntariado, doações e participação em eventos.

2. Estrutura de Páginas
O site é composto por 8 páginas principais, cada uma com um propósito específico e estrutura semântica bem definida:

index.html (Página Inicial): A porta de entrada do site, com destaques sobre o impacto da ONG, projetos em evidência e um apelo à ação claro para doações e voluntariado.

sobre.html (Sobre a Organização): Apresenta a história, missão, visão e valores da ONG. Inclui um vídeo institucional e depoimentos em áudio para criar uma conexão emocional com o visitante.

projetos.html (Projetos Sociais): Detalha as frentes de atuação da organização, inclui um formulário de inscrição para interessados e uma galeria de fotos responsiva com 20 imagens.

voluntariado.html (Voluntariado): Contém um formulário de cadastro complexo para novos voluntários, permitindo a recolha de dados pessoais, habilidades e disponibilidade.

doacoes.html (Como Doar): Fornece informações claras sobre como contribuir financeiramente (PIX, transferência) e também através da doação de itens.

transparencia.html (Transparência): Demonstra o compromisso da ONG com a responsabilidade, exibindo gráficos de dados (distribuição de recursos, evolução de voluntários) e uma tabela para download de relatórios.

contato.html (Contato): Disponibiliza um formulário de contato completo com diferentes tipos de input (incluindo anexo de arquivos), além de informações de endereço, telefone e um mapa de localização.

blog.html (Blog/Notícias): Uma área para a publicação de notícias, histórias de sucesso e artigos, mantendo a comunidade informada e engajada.

3. Funcionalidades e Requisitos Técnicos Implementados
O projeto foi construído para atender a uma série de requisitos técnicos modernos:

Estrutura HTML5 Semântica: Todas as páginas utilizam tags como <header>, <nav>, <main>, <section>, <article>, <aside> e <footer> para uma melhor acessibilidade e SEO.

Formulários Complexos e Interativos:

Cadastro de Voluntário: Com agrupamento de dados (<fieldset>), diversos tipos de input (date, range, checkbox), validação nativa e máscaras de JavaScript para CPF, telefone e CEP.

Inscrição em Projetos: Utiliza textarea com minlength e select para seleção de projetos.

Contato Institucional: Inclui datalist para sugestão de assuntos e input do tipo file para anexos.

Newsletter: Com validação de e-mail e checkbox para preferências.

Recursos Multimédia Avançados:

Galeria de Fotos Responsiva: Uma grelha com 20 imagens que se adapta a diferentes tamanhos de ecrã.

Vídeo Institucional: Integração de vídeo do YouTube através de <iframe>.

Player de Áudio: Uso do elemento <audio> para depoimentos.

Imagens Otimizadas: Uso do elemento <picture> para servir imagens diferentes em ecrãs distintos e loading="lazy" para otimizar o carregamento.

Elementos Gráficos e Visualizações:

Utilização do elemento <canvas> com a biblioteca Chart.js para criar três tipos de gráficos:

Gráfico de Pizza (Distribuição de recursos).

Gráfico de Linha (Evolução de voluntários).

Gráfico de Barras (Impacto social por região).

4. Tecnologias Utilizadas
HTML5: Para a estrutura e semântica do conteúdo.

CSS3: Para estilização, através do framework Tailwind CSS.

JavaScript (ES6+): Para interatividade, manipulação do DOM (menu móvel), máscaras de formulário e inicialização dos gráficos.

Tailwind CSS (v3): Framework CSS "utility-first" para a criação rápida de um design moderno e totalmente responsivo. Utilizado via CDN.

Font Awesome: Para ícones. Utilizado via CDN.

Google Fonts: Para a tipografia (família de fontes "Inter").

Chart.js: Biblioteca JavaScript para a criação de gráficos e visualização de dados. Utilizada via CDN.
